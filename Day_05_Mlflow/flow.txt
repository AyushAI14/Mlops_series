5. Remote tacking server - dagshub
- login to dagshub via github
- making a duplicate file of index.py 
- make new repo in dagshub and connect you github repo
- pip install dagshub and import it to your file like this : 
        import dagshub
        dagshub.init(repo_owner='AyushAI14', repo_name='Mlops_series', mlflow=True)
        mlflow.set_tracking_uri('https://dagshub.com/AyushAI14/Mlops_series.mlflow')
- run the file it should run and give you the remote tracking link

7. hypertuning
- you can set up gridsearchcv and set log for traning/test data , best_model , and more
- to see all your gridsearchcv result set mlflow.start_run() as parent
    # log all the child runs
    for i in range(len(grid_search.cv_results_['params'])):

        with mlflow.start_run(nested=True) as child:
            mlflow.log_params(grid_search.cv_results_["params"][i])
            mlflow.log_metric("accuracy", grid_search.cv_results_["mean_test_score"][i])
- go to ui and you will seen all childs runs under plus icon of yor current exp
